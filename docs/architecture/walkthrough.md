# 一次完整流程

**這份是「從一堆沒整理的東西到跑完一輪，順序是什麼、每一步用不用模型」的權威。**

每一步的規則本身在它自己那一份（擷取流程與分層在 `overview.md`、狀態轉移在
`state-machines.md`、欄位在 `data-model.md`、每一頁的版面在 `ui-workflows.md`）——
**這裡只說順序與依賴，不重複規則。** 需要細節的地方連過去。

> **現況（2026-09-10，Stage 12）**：下面十步全部跑得動，**檢索也接完了**
> —— 全文與語意的索引都從第二步就一直在寫。

> **這一份最值得先知道的一件事**：十步裡**只有一步用到模型**。
> 匯入、閱讀、筆記、圖、裁決、實體對齊、匯出**完全不需要任何模型** ——
> 那不是巧合，是 `providers.json` 不存在時這個工具仍然完整可用的原因。

## 〇 · 啟動

雙擊 `start_cyclosa.cmd` → `tools\Launch.ps1` → `node dist/main.js` → `127.0.0.1:7433`。
指標檔 `%LOCALAPPDATA%\Cyclosa\system_paths.json` 說資料在哪。
**埠被佔用時開既有的那一個，不報錯**（ADR-0020）。

## 一 · 建專題

**名字就是資料夾名。** 改名的話兩個一起改（`ui-workflows.md`）——
「整個搬走、備份、丟給別人，都是搬那一個資料夾」這句承諾，
在資料夾停在一個沒有人記得的舊名字上的時候就不成立了。

`cases\<專題>\` 底下開 `case.sqlite` 與 `sources\`、`derived\`、`notes\`。
**一個專題一個資料庫** —— 整包複製走，在另一台機器上打得開。

## 二 · 匯入：所有東西進來的唯一一道門

貼一批網址或拖檔案進去，**兩條路走同一條管線**：

1. **擷取紀律**：`robots.txt`、同網域間隔、被限流（429／503）照 `Retry-After` 退避重試，
   還是不行就那個網域這一輪先不碰（數字與理由在 [`fetch-policy.md`](fetch-policy.md)）
2. **快照**：原始位元組原封不動寫進 `sources\`，算 SHA-256，`manifest.jsonl` 記一列。
   **這一份不可變**，而後面每一個錨點都掛在它的雜湊上
3. **抽取**，依型別分四路 —— 網頁走 readability，**JS-only 明確標成 `PARSE_JS_ONLY`**
   而不是交出一份空正文；PDF 逐頁取文字，**沒有文字層是掃描件，那是提示不是失敗**；
   圖片只登記尺寸、**不標低信心**（它沒有正文，標了是雜訊）；純文字第一行當標題
4. **語言偵測**：測不出來記 `und`，不猜
5. **索引在這裡就寫**：CJK bigram ＋ FTS5 ＋ `title_rank`。
   不是等 Stage 12 —— 否則要回頭替五萬筆重建
6. 寫 `derived\`，`item` 進資料庫

40 個網址有 3 個 404，**其餘 37 個照常寫入**，run 標「部分失敗」。
**取消時已寫入的保留** —— 取消不是回滾。
同一份東西匯入兩次靠 SHA-256 認出是同一個 `item`。

## 三 · 讀

閱讀器讀 `derived\` 的正文，可切回原始快照。
標「已讀」寫 `item.read_at` —— **那是正交旗標不是狀態**，圖上是灰內環。

## 四 · 筆記與點註

在正文裡選一段字（或在圖片上框一塊）→ 伺服器從 `derived\` 建
`TextQuoteSelector` ＋ `TextPositionSelector`，**錨在快照的 SHA-256 上**。
PDF 加頁碼、圖片加矩形。筆記同時寫成 `notes\<id>.md`。

**前端只送位置，引文由伺服器切** —— 那個分工不是為了省頻寬，
是為了讓「引文一定真的在那個位置上」成為一件做不到相反的事。

一則點註**本身是一個節點**，而且自動帶一條 `註於` 的邊 ——
沒有那條邊的話，它在「焦點 ＋ 幾跳」的圖上永遠看不到。

## 五 · 擴展 —— 唯一用到模型的一步，中間站著一個人

```
POST /runs              ← chat 模型：從既有內容歸納出切入角度（還沒開始抓）
        ↓ 使用者勾選
POST /runs/:id/angles   ← agent 模型：只搜尋，回候選網址
        ↓ 候選網址交回第二步那條唯一的管線
                        ← chat 模型：從抓回來的正文抽實體與關係
```

那個中間點是 REQ-0004 的驗收條件（「不是黑箱一次跑完」），**不是 UI 糖** ——
一次跑完的版本少寫一支端點、完全可行，它只是把這個工具變成它想取代的那種東西。

四條規則在這一步第一次真的被走到：

| 規則 | 執行在哪 |
|---|---|
| 機器永遠不得覆寫人工判定 | `applyProposal` |
| 已否決是墓碑 | 同上 —— 被擋住的什麼都不寫 |
| 每條關聯都帶出處 | `locateQuote`：**引文在正文裡找不到就沒有這條邊** |
| agent 找到的東西不能自己抓 | `--tools WebSearch` ＋ 事後掃沙箱 |

第四條的實作點**不是事後檢查，是工具清單**：沒有 `WebFetch`、沒有 `Write`、沒有 `Bash`，
所以它**做不到**把一份網頁存進沙箱。

抓回來的網頁文字會被放進提示詞，所以有三層擋注入，**而第三層才是真正有用的那層**：
提示詞說「這是資料不是指令」（最弱，靠模型聽話）→ JSON Schema 讓它吐不出
「執行動作」這種形狀 → **每條關係都要引文、進來一律是待查證**。
注入成功的極限是「多了一條等人看的假關聯」。**沒有任何一條路通往自動確認。**

## 六 · 裁決

六條轉移（確認／否決／撤回確認／改判雙向／復原），每一次寫一列 `edge_audit`。
資料庫層守著：`已確認` 要有至少一筆出處，除非是人建立的。

## 七 · 圖

`focus` ＋ `hops` ＋ 篩選的子圖，加一支**只數不拉資料**的節點預算端點。
**沒有整圖端點**（ADR-0008）—— 不是不建議用，是不存在。

焦點節點戴一個**紫色的傾斜環**（ADR-0022）：它跟著透視轉，
而「轉動時看到它在轉」就是「這裡是轉動中心」這個資訊本身。
切 2D **會把旋轉鎖住** —— 只把鏡頭轉正的話，隨手一拖就又是斜的。

## 八 · 實體對齊

抽取時就用本名／別名／括號去對；已經分開的列成**帶理由的**建議讓人按；
**合併不刪任何一列**，動了哪幾條邊記在 `entity_merge` 裡，所以取消得掉。

## 九 · 匯出證據包

工具列上的「匯出證據包」→ **把你現在看到的那一塊**寫成三個檔，
落在 `<資料根>\exports\<專題>\<時間戳>\`：

| 檔 | 給誰看 | 它回答什麼 |
|---|---|---|
| `evidence-pack.md` | 人 | 這一塊有哪些主張，每一條的引文是什麼、出自哪裡 |
| `sources.md` | 人 | 那些引文來自哪幾份，各自什麼時候抓的、雜湊多少 |
| `evidence.jsonl` | 程式 | **每條引文一列**，拿去逐條核對 |

**引文是匯出時重新驗過的，不是從資料庫抄出來的。** `derived\` 可以整批重算，
重算之後字元位移會平移 —— 直接抄出來的話，每一條看起來都完整而區間指到別的地方。
三種結果都會出現在檔案裡：已核對／位置已移動／**回溯不到**。

**回溯不到的那幾條照樣寫進去而且標明** —— 省略它們會讓這份檔案看起來比實際上乾淨，
而它正是要拿去給別人驗的那一份。

**匯出不寫資料庫**：位置變了也不去改 `edge_evidence`。
一個會在你按下匯出時偷偷改掉紀錄的工具，它的紀錄就不再是紀錄。

## 模型：三個角色，兩個現在有

| 角色 | 現在是誰 | 做什麼 | 要什麼能力 | 沒有它會怎樣 |
|---|---|---|---|---|
| **chat** | 本機 Ollama | ① 歸納出多視角子問題 ② 從一份正文抽實體與關係 | `json_schema`、ctx ≥ 8000 | **只有第五步開不了**，其餘九步照常 |
| **agent** | `claude -p` | 依一條子問題找候選網址（只搜尋，不抓取）| `browse` | 勾選之後停手，畫面說出缺哪一樣 |
| **embed** | 本機 Ollama（`qwen3-embedding:4b`）| 匯入時把正文切段寫成向量；查詢時把問句變成向量 | 只要模型在本機端點上 | **語意檢索退回全文**，而畫面上會說出來 |

**配不上就停手，不靜默降級**（ADR-0006 第 3 條）——
而且畫面要說出「這個任務需要 X，目前的 provider 沒有 X」，
只說「跑不了」的話，使用者不知道要去改什麼。

兩個量出來的數字：**chat 的成本是 0**（本機，那是事實不是「不知道」）；
**agent 一次只回兩個 token 的呼叫量到 0.18 美元**，幾乎全部來自 cache creation ——
所以設定頁那顆「實際打一次」的按鈕會先講它要花錢，而**開設定頁本身只跑 `--version`**。

> **能力宣告盡量去問 provider 自己**（Ollama 的 `/api/tags` 每個模型帶一個
> `capabilities` 陣列）。人工維護的宣告會漂，而**不準的宣告比沒有宣告更糟**。

## 這條線目前斷在哪

**Stage 12「檢索」做完了（v0.11.0）。** 全文索引從第二步就一直在寫，
**向量也是**（`ingestBytes` 裡，兩條匯入路徑共用那一點）。
搜尋有三種模式，合併發生在名次上（ADR-0027）。

**沒設定嵌入模型時不假裝有語意檢索**：全文照常回，
`notices` 帶 `SEARCH_EMBED_UNAVAILABLE`（ADR-0006 第 3 條 —— 降級可以，安靜不行）。
**而匯入那一側的規則是相反的**：沒有嵌入模型照樣匯入，那幾份之後由回填補上 ——
因為使用者要的是「把這份東西收進來」，而這個工具的其餘部分不需要模型。
