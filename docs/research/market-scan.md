## 結論：七個賽道，沒有一個涵蓋這個組合

要找的組合是：**主動擴展 ＋ 每條關聯帶出處 ＋ 圖瀏覽 ＋ 內建閱讀器 ＋ 本機保存 ＋ 可續接**。

| 賽道 | 代表 | 缺什麼 |
|---|---|---|
| **筆記圖** | Obsidian、Logseq、Heptabase、Scrintal、TheBrain | 線**全靠人手動連**、型別扁平、無爬取、無出處 |
| **AI 研究助理** | NotebookLM、Anara、Elicit | 綁單一模型、來源數上限、**無圖**、無本機保存、筆記本之間不能互查 |
| **調查／OSINT** | Aleph、Datashare、Maltego、i2、Linkurious | 要 Docker＋Elasticsearch 或商業授權、無 3D、**LLM 不主動擴展**、繁中弱 |
| **文獻圖譜** | Connected Papers、ResearchRabbit、Litmaps、Inciteful | **只吃論文**；關係型別不可自訂 |
| **LLM 圖譜函式庫** | GraphRAG、LightRAG、cognee、Graphiti | **是函式庫不是應用**：無 UI、無閱讀器、無人工裁決 |
| **保存／稍後讀** | ArchiveBox、SingleFile、Karakeep、Linkwarden | **沒有關聯圖**，也不做擴展 |
| **深度研究代理** | STORM、GPT-Researcher、Open Deep Research | **輸出是一篇報告**，不是可累積、可續接、可再展開的結構 |

台灣本地也沒有對手（資策會的「III 知識圖譜標記工具」是面向企業的**標記工具**）。

## 六個直接改變設計的發現

### ① Obsidian 圖被批評「好看但沒用」，而原因具體且可修

社群歸納三條：關係層唯讀（**沒辦法把剛想到的關係拖出來**）、圖沒有型別
（**無法「只顯示人」**）、超過約 500 節點只是變擠。Excalibrain 靠**具名連結**造層次。

→ **反過來就是必要條件**：邊要可手動建立、節點與邊要有型別且可篩選、預設只渲染子圖。
**借的是概念。**

### ② 3D 在 HCI 研究裡不是免費的升級

遮擋與深度感知讓「精確比較」「社群偵測」比 2D 慢；3D 的優勢在**空間記憶與整體結構感**。

→ **3D 只做瀏覽與結構感**，精確操作（比對、篩選、確認邊）在側欄的 2D 面板，
**必須提供一鍵切 2D 平面佈局**。旋轉時給深度線索（霧化、近大遠小、選中連線高亮）。
**寫進 ADR-0007**，否則日後有人會把分析功能塞進 3D。

### ③ 焦點＋脈絡與語意縮放是成熟解法

關注度決定顯示層級；縮放時**改變表示型態**而非只放大。

→ 子圖 API 直接對應 `focus` ＋ `hops` ＋ `filters`；近距離顯示標題與縮圖，
遠距離只顯示形狀與顏色。**借的是概念。**

### ④ 正文抽取有公開評測

2026 WCXB：`rs-trafilatura` F1 0.910、Python `trafilatura` 0.883、
**Mozilla Readability 中位數 0.970 最高但平均較低**（簡單頁很穩、複雜頁掉得快）。

→ Node 端用 `@mozilla/readability`（Apache-2.0，**當依賴**）＋ `linkedom`，
**並記錄抽取信心值**；信心低的標記出來，**不靜默交出爛正文**。

### ⑤ 標註錨點的標準答案已經存在

**W3C Web Annotation Data Model。** Zotero 與 Hypothes.is 都**同時存
`TextPositionSelector`（快）與 `TextQuoteSelector`（抗漂移）**。

→ 直接採用。快照不可變，所以錨點**釘在 snapshot 上**，重構排版只是投影 ——
抽取演算法改版重跑時點註不會掉。
**借的是規格與概念，Zotero 的程式碼一行都不碰（AGPL）。**

### ⑥ STORM 的「多視角提問」是擴展策略的現成處方

引用召回率／精確率約 85%。

→ 擴展主題時先由 `agent` 產生多視角子問題再各自檢索；
**子問題本身就是好 UI**（讓使用者勾選展開哪幾條）。**借的是概念。**

## 兩個從別的賽道學到的「不要做」

- **不做報告產生**（深度研究代理那一欄的共同問題）。一個會生成散文的工具，
  使用者就不會回去看出處了 —— 而出處是這整個東西的重點。
  只匯出「選取子圖的證據包」（Markdown ＋ 引文 ＋ 來源清單）。
- **不做「一鍵生成關聯圖」**（LLM 圖譜函式庫那一欄）。沒有人工裁決的圖，
  看起來很有道理但沒有人敢用。所以邊的狀態機規定**機器永遠不得覆寫人工判定**。
