# REQ-0006：閱讀器與筆記

**狀態**：草稿
**日期**：2026-09-06

## 使用者要什麼

在工具裡**直接讀**（不用跳出去開瀏覽器），選一段文字寫註記，
**那段註記之後找得回來、而且不會因為工具改版而漂掉**。

最後半句是重點。點註漂掉一次，使用者之後就不會再標 ——
跟關聯被機器覆寫一次之後就沒有人再確認，是同一件事。

## 驗收條件

- [ ] 第一版支援：**網頁快照／Markdown／純文字、PDF、圖片**。
- [ ] 選一段文字建立點註，**同時存 `TextQuoteSelector` 與 `TextPositionSelector`**。
- [ ] **重跑抽取（`derived/` 整批重算）之後，所有點註仍指到同一段文字**
      （可驗：重算前後對每個點註的解析結果做比對，差異必須為 0）。
      **這條是 ADR-0010「錨點釘在快照上」的驗收。**
- [ ] **點註在圖上是節點**，可以參與關聯 ——
      使用者自己的判斷與蒐集來的資料在同一張圖上。
- [ ] **筆記同時寫成 `notes/*.md` 純 Markdown**，
      離開這個工具用任何編輯器都讀得到。
- [ ] 閱讀器裡看得到這一份的**抽取信心標記**（REQ-0003）與原始 URL。
- [ ] **失敗路徑**：錨點解析失敗時顯示「找不到原文位置」，
      **保留註記內容**，不靜默丟掉，也不錨到錯的地方。

## 刻意不做

- **協作註記／多人。** 這是單機工具。
- **註記的版本歷史。** 第一版沒有；筆記是 Markdown，要版本自己丟進 git。
- **在 `derived/` 上錨定。** 那正是 ADR-0010 排除掉的做法。
- **影音的時間軸註記。** 第一版沒有影音來源。
