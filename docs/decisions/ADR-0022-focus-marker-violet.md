# ADR-0022：焦點改用紫色的一個環 —— 推翻 ADR-0018 的白色準星

**狀態**：已採用。**2026-09-08（Stage 11 收尾的人工驗收）實作。**
**日期**：2026-09-08

## 背景

ADR-0018 訂的焦點畫法是**白色準星 ＋ 傾斜環**，而白色的理由寫得很清楚：

> 白色可以拿來做這件事，**正是因為它已經從資料層退出來了** ——
> 圖上沒有別的東西是白的。

那個推理是對的，而它解的是「不要跟資料的顏色撞在一起」這個問題。
**它沒有解另一個問題**：白色在深色背景上是整張圖亮度最高的東西，
而焦點節點永遠停在畫面正中央 —— 於是**最亮的東西永遠壓在你最想讀的那個標籤上**。

2026-09-08 的人工驗收就是撞到這個：使用者的原話是
「中心點的兩圈白圈太干擾閱讀關聯圖」，而且要求「用不同顏色，不是變黑或變淡」。

### 量測：顏色預算是滿的

ADR-0018 用 **OKLab ΔE ×100**（本文重跑同一把尺，四個校準點全部吻合：
藍對洋紅 26.5／色盲 16.0，紫 `#8156c0` 對藍 14.3，洋紅對灰色盲 5.3，
暖色 `#c96a3c` 對琥珀 12.5）並訂了**正常視覺 ΔE ≥ 15** 的硬底線。

用那把尺掃 OKLCH 色域（色相 0–360 每 3 度、L 四段、彩度四段，1071 個在色域內的候選），
要求對圖上**每一個**既有顏色都 ≥ 15：

> **零個候選通過。最好的一個只有 12.5。**

這正是 ADR-0018 的「什麼情況要重新考慮」預期的處境：
**出現第八件要在圖上表達的事**時，先問它能不能不上圖，再問能不能用形狀，最後才問顏色。

## 決定

**一、放寬比對集合，而且把放寬的理由寫下來。**

焦點的記號是一個**環**。圖上另外只有兩個環（選取青、已讀灰），
而節點是實心方塊、關聯是線 —— **形狀本身就是第二重編碼**（ADR-0018 規則 2）。
所以門檻改成：**對另外兩個環**要 ≥ 15（正常）／≥ 10（色盲），對背景 ≥ 45；
對節點與線的距離**照樣量、照樣寫下來，但不當門檻**。

用這組門檻重掃，284 個候選通過。

**二、選 `#c68bff`（紫，OKLCH H 306 · L 0.74 · C 0.17）。**

| 對誰 | 正常 | 色盲 |
|---|---:|---:|
| 選取青 `#35d6c4` | 27.0 | 13.0 |
| 已讀灰 `#8b93a3` | 17.2 | 12.9 |
| 背景 | 58.7 | 55.6 |
| 待查證琥珀 | 28.7 | 27.2 |
| 筆記洋紅 | 19.7 | 18.1 |
| 已否決灰 | 24.4 | 20.4 |
| **資料藍 `#3987e5`** | 18.6 | **6.4** ← 最弱的一對 |

**三、兩個記號併成一個。**

準星（永遠正對鏡頭的平面環）與地平線環（躺在 XZ 平面、跟著透視傾斜）
**講的是同一件事**，而它們一起把標籤夾在中間。留傾斜環，因為
「轉動時最先看到它在轉」正是「這裡是轉動中心」這個資訊本身 ——
平面準星給不出那個資訊。

環從 2.4 倍節點縮到 1.6 倍，不透明度 0.55 → 0.85
（**看得清楚的細環比看不清楚的粗環干擾更小**），
標籤從 1.1 倍高度移到 2.2 倍 —— 那個數字是被環的半徑決定的，不是排版偏好。

## 考慮過但沒選的

| 選項 | 為什麼沒選 |
|---|---|
| **把焦點節點的填色換成紫** | 填色 ＝ 這是什麼（藍＝抓回來的、洋紅＝你寫的）。換掉之後**焦點節點是唯一一個看不出來歷的節點**，而它正是你最在意的那一個 |
| 橘 `#c56b23` | 色盲表現最好，但對待查證琥珀只有正常 11.8 —— 而琥珀虛線到處都是 |
| 萊姆綠 `#9ed313` | 對琥珀色盲 7.7；而且 ADR-0018 明訂**綠只在面板、圖上永不出現** |
| 維持白色只縮小 | 使用者要的是顏色，而且「兩個記號講同一件事」那一半跟顏色無關 |
| 不上顏色、改用形狀（例如底座）| 轉動中心的線索會消失 —— 而那是這個記號存在的理由 |

## 代價

- **色盲下紫環對藍色節點只有 6.4。** 焦點節點常常就是一份資料（藍方塊），
  所以綠紅色盲的使用者會看到「藍方塊外面一圈藍環」。
  撐住它的是**形狀與位置**（一個環，離節點有距離），不是顏色 ——
  這是 ADR-0018 規則 2 在這一條上真正被用到的地方。
- **圖上的顏色又多了一個。** 下一件要上圖的事幾乎確定沒有顏色可用了。
- 這組數字跟 ADR-0018 一樣**綁在深色骨架上**。背景一改要全部重算。
- **放寬門檻這件事本身是一個先例。** 之後每一次「環只跟環比」的論證，
  都要重新確認那個形狀真的不會跟被比較的東西混淆。

## 什麼情況要重新考慮

- **色盲使用者實際回報分不出焦點環與藍色節點** —— 那時要動的是形狀
  （例如環改成雙線或加缺口），不是再換一個顏色：**沒有顏色可以換了。**
- **要加淺色主題** —— 跟 ADR-0018 同一條，整組要重算。
- **圖上再出現第二個環以外的記號要用顏色** —— 那時「環只跟環比」這個放寬
  就不再成立，要退回全域門檻重新掃一次。
