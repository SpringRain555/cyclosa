## 使用者要什麼

2026-09-18 第一次拿一篇真的論文走完「建專題 → 匯入 → 擴展」之後（十四點的第 2、12 點）：

> 擴展強迫我選角度，選項不是我要的、也不夠多。擴展到底在做什麼？
> 我要的是像 Codex／Claude Code 的 **deep research ＋ plan**：先跟模型談出蒐集的方向，
> 而且確認那些方向跟這個專題有關 → 蒐集 → 列出候選（**能抓的工具抓、要人拿的人拿，拿不到的說原因**）
> → 逐筆確認狀態 → 建圖。

同一輪問答裡另外定下來的（ADR-0033「由來」有完整的表）：

- 研究可以直接從主題開始；**要拆方向的話，切分要明確、有意義、盡量窮舉**，不是隨意幾條
- 「跟專題有沒有關」用**已有的資料**算（全文檢索），不花錢
- 多次研究之後要有「**整理**」：合併重複實體、把沒抽過的資料抽進圖、找漏掉或標得太弱的關聯、補繁中名與分類
- 拿不到正文、但選了「保留並紀錄」的來源**進圖**，當「只有書目、沒有正文」的節點
- 點節點看得到的東西（標題、摘要）可以切繁中；**全文不翻** —— 使用者自己做的完整譯文當筆記掛上去
- 使用者自己準備的**筆記檔要能上圖**；整理時連筆記一起看
- **刪除**刪的是那一次研究的對話紀錄，不是還原資料庫（圖可以直接編輯，每次研究調到滿意才跑）
- 分工：Claude CLI 當總控制（規劃對話、找來源，吃訂閱額度）；OpenAI 相容端點（使用者的 kano-proxy）
  負責大量讀取、初步判斷、摘要翻譯、抽取

## 驗收條件

### 規劃（Stage 19）——  ✅ 2026-09-20 做完，未出貨

- [x] **R1** 輸入主題的**當下**、還沒有任何模型呼叫之前，畫面先說「你已有的 N 份裡 K 份提到它」，
      並列出那 K 份的標題與命中的那一段（全文檢索，不花錢）。K 是 0 也照說。
- [x] **R2** 可以**直接用主題開始**（一條方向＝主題本身，零次規劃呼叫），也可以**跟模型談**。
- [x] **R3** 談的時候模型看得到專題的摘要（資料標題、實體、R1 命中的段落），
      每一輪交出一份**規劃**：方向清單 ＋ 一句「這個主題跟專題的關係」＋ **刻意不查的範圍**。
      每條方向寫明要找什麼、預期哪一類來源、關鍵詞。
- [x] **R4** 使用者可以直接**改、加、刪**方向（不必透過模型），改過的方向標「你改的」。
- [x] **R5** **閘門一**：按「照這份規劃開始」之前，**不會有任何搜尋或擷取**。
      按鈕旁邊先說接下來哪幾步會花錢、走哪一個服務。
- [x] **R6** 方向的數目沒有下限；上限寫在程式裡（草案 12），**超過就說，不靜默截掉**。
      沒被採用的方向也留著（「提了哪些、你留了哪些」是這次研究的一部分，跟 `run_angle` 同一個理由）。

### 蒐集（Stage 20）

- [ ] **R7** 每條方向各自找來源，結果是一張**候選清單**：網址、標題、為什麼、屬於哪條方向、
      預期拿不拿得到（公開／多半要登入／不知道）。
- [ ] **R8** **能抓的由擷取管線抓**（robots、節流、雜湊、manifest 全部照舊）；
      依使用者自己的紀錄多半要登入的網站**不去試**，直接列成「要你拿」。
- [ ] **R9** 抓失敗的候選**說原因**（付費牆、要登入、對方出驗證頁、robots 不准、找不到頁面），
      每一種是既有的錯誤碼，不是一個「失敗」。
- [ ] **R10** 使用者可以把自己拿到的檔案**對回某一條候選**上傳；出處仍然指得回那條候選的原始網址。
- [ ] **R11** 拿不到的候選，使用者選原因：付費牆／沒帳號、找不到這一份（可能是模型編的）、被擋、其他（自由填）。
- [ ] **R12** **閘門二**「完成蒐集」：按下去之後不再找、不再抓新的候選。蒐集期間抓回來的可以先在閱讀器裡讀；
      **閘門三之前，一條關聯都不寫進圖**。
- [ ] **R13** 關掉程式再開，蒐集到一半的研究**停在原處**，按「繼續蒐集」接著做，已抓的不重抓。

### 初讀：判斷與繁中（Stage 21）

- [ ] **R14** 每一份抓回來（或上傳）的候選，由模型讀一次，給：跟這次研究有沒有關（有／沒有／說不準 ＋ 一句理由）、
      繁中標題、繁中摘要（兩三句）。**走哪一個服務照設定頁的「模型分工」**（預設 Ollama；
      設成 OpenAI 相容 API，就是 kano-proxy 在讀）。
- [ ] **R15** 繁中標題與摘要是**衍生物**：原文欄位永遠不被覆蓋；刪掉所有譯文欄位之後原文完全不變
      （`multilingual.md` 那條可驗的規則）。節點面板與閱讀器可以切原文／繁中，旁邊寫**哪個模型、什麼時候**產生的。
- [ ] **R16** 全文不翻。

### 確認與建圖（Stage 22）

- [ ] **R17** 確認畫面逐筆列出候選，每一筆給**最終狀態**：進圖（有正文）／只留書目／丟掉。
      預設值由查得到的事實決定（抓到而且初讀說有關 → 進圖；拿不到 → 只留書目；初讀說無關 → 丟掉），
      使用者可以改。每條方向拿到幾份、缺幾份，**用數的，不用模型說**。
- [ ] **R18** **閘門三**：每一筆都有最終狀態，「開始建圖」才按得下去。
- [ ] **R19** 建圖時「進圖」的每一份都走 `applyExtraction`（包括使用者上傳的）——
      實體對齊、共同提及、`locateQuote`、待查證、墓碑，**一條規則都不另寫**。
- [ ] **R20** 「只留書目」的建成書目節點（`kind='reference'`）：有標題、網址、為什麼、拿不到的原因，**沒有正文**。
- [ ] **R21** 「丟掉」的：抓回來過的標「已排除」（可以復原）；沒抓過的只在這次研究的紀錄裡。
- [ ] **R22** 建完之後可以一鍵「在關聯圖上看這一次新增的」。
- [ ] **R23** 一份抽壞了不影響其餘（部分完成是一等公民）；已寫入的保留。

### 筆記檔上圖（Stage 23）

- [ ] **R24** 在閱讀器與節點面板上「附上筆記檔」：一份 `.md` 掛到這個資料節點上，成為一則**整份的**點註，
      圖上是一個筆記節點連到那份資料。使用者自己的完整譯文走這一條。
- [ ] **R25** 匯入頁拖進來的 `.md` 仍然是**資料**節點 —— 兩條路分開，畫面各自說清楚是哪一種。

### 整理（Stage 24）

- [ ] **R26** 對整個專題跑：模型讀專題的摘要（實體表、只有一條出處的關聯、還沒抽過的資料、筆記），
      交出一份**操作清單**：合併哪兩個實體、抽哪幾份、加哪條關聯（附引文）、改哪個實體的型別、補哪些繁中名。
- [ ] **R27** 每一條操作**逐條勾**才執行，執行走既有的服務（實體合併、`applyExtraction`、
      `applyProposal` ＋ `locateQuote`、實體更新）—— **不另寫規則**；加關聯的引文一樣要在原文裡找得到。

### 跨階段

- [ ] **R28** 同一個專題**同時只有一次研究或整理**還沒結束；匯入可以並行。
- [ ] **R29** 每一次模型呼叫（規劃的每一輪、找來源、初讀、抽取）照 v0.22.0 的診斷開關留紀錄；
      研究的畫面上看得到**到目前為止實際花了多少**（provider 沒回報就寫「不知道」，不寫 0）。
- [ ] **R30** 「刪除這次研究」刪的是對話、方向、候選的紀錄與那次的模型呼叫紀錄；
      **寫進圖裡的東西不動**（要拿掉用既有的「復原這次作業」，ADR-0023）。刪之前說清楚刪什麼、不刪什麼。
- [ ] **R31** 舊的擴展紀錄在升級時清掉（ADR-0033 D17）：先備份 → 每一筆各做一次既有的「復原」
      （你裁決過的、你動過的、還被當出處的都留著）→ 刪紀錄 → 畫面說一次清了什麼、為什麼留下那幾份。
      舊資料**不遷移成研究**。

## 不變的規則（這一份不放寬任何一條）

| 規則 | 在哪裡 |
|---|---|
| agent 找到的東西不能自己抓，一律走擷取管線 | ADR-0006 第 5 條、`--tools WebSearch` ＋ 事後掃沙箱 |
| 每一條具名關聯都要帶**找得到的**引文 | ADR-0005、ADR-0021（`locateQuote`：找不到就沒有這條邊）|
| 機器永遠不得覆寫人工判定；已否決是墓碑 | ADR-0016 |
| 不做報告產生 | REQ-0004「刻意不做」|
| 模型的輸出是外部輸入（格式驗過、編號對過才用）| ADR-0021 |
| 不繞過付費牆、登入、CAPTCHA；遵守 robots | CONVENTIONS §17、`fetch-policy.md` |
| 配不上就停手，不自動換一個能力較弱的 | ADR-0006 |

## 刻意不做

- **自動確認高信心的邊。** 三道閘門是工具停下來等人的地方（其中兩道擋在花錢之前），不是「確認關聯」的捷徑。
- **研究結束時產生一份報告或結論。** 規劃裡的「跟專題的關係」是一句話的方向說明，不是結論。
- **替使用者登入、代填帳號密碼、繞過驗證頁。** 拿不到就是拿不到，說原因、讓人去拿。
- **全文翻譯。**
- **把舊的擴展紀錄轉成研究。** 兩者的形狀不同，轉出來的東西會假裝經過了它沒經過的閘門。
